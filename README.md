## ЯЧЕЙКА 3: Загрузка данных наблюдений

```python
def load_observations(filename):
    observations = []
    with open(filename, 'r', encoding='utf-8') as f:
        lines = f.readlines()
        data_lines = lines[1:]  # Пропускаем первую строку (заголовок)
        for line in data_lines:
            line = line.strip()
            if not line:
                continue
            
            # Разбиваем строку на части
            parts = [x for x in line.split() if x]
            if len(parts) < 12:
                continue
            
            # Извлекаем компоненты
            date_ut = ' '.join(parts[0:3])           # Дата в UTC
            ra = ' '.join(parts[3:6])                # Прямое восхождение (Right Ascension)
            dec = ' '.join(parts[6:9])               # Склонение (Declination)
            magn = parts[9]                          # Магнитуда (яркость)
            
            # Магнитуда может иметь дополнительный символ (R, V, B и т.д.)
            location_start = 10
            if len(parts) > 10 and parts[10].isalpha() and len(parts[10]) == 1:
                magn += ' ' + parts[10]
                location_start += 1
            
            # Название обсерватории (может состоять из нескольких слов)
            location = ' '.join(parts[location_start:-2]) if len(parts[location_start:-2]) > 0 else ''
            ref = ' '.join(parts[-2:])               # Ссылка на каталог
            
            # Проверяем, что все данные загружены корректно
            if not all([date_ut, ra, dec, magn, location, ref]):
                continue
            
            obs = {
                'date_ut': date_ut,
                'ra': ra,
                'dec': dec,
                'magn': magn,
                'location': location,
                'ref': ref
            }
            observations.append(obs)
    return observations

filename = 'sample_data/2023_BU_data.txt'
obs = load_observations(filename)
print('Число загруженных наблюдений:', len(obs))
print('Пример наблюдения:', obs[0])
```

**Что это делает:**

Функция `load_observations` читает файл с астрономическими наблюдениями и парсит (разбирает) каждую строку:

- **`lines = f.readlines()`** — читаем все строки из файла
- **`data_lines = lines[1:]`** — пропускаем первую строку, там заголовки
- **Для каждой строки:**
  - **`date_ut`** — дата и время наблюдения (2023 01 21.342991 = 21 января 2023, время 0.342991 суток)
  - **`ra`** — прямое восхождение (координата на небе, как долгота, но для неба). Формат: часы минуты секунды
  - **`dec`** — склонение (как широта на Земле). Формат: градусы минуты секунды
  - **`magn`** — видимая яркость (21.19 R = 21.19 звёздных величины в фильтре R)
  - **`location`** — какая обсерватория сделала наблюдение
  - **`ref`** — номер записи в каталоге

**Результат:**
- Загружено **1753 наблюдения**
- Первое наблюдение: астероид видели 21 января 2023 года с Палнмар-Маунтин обсерватории, яркость 21.19

## ЯЧЕЙКА 6: Парсинг даты

```python
def parse_date(date_str):
    parts = date_str.split()  # "2023 01 21.342991" → ["2023", "01", "21.342991"]
    year = int(parts[0])
    month = int(parts[1])
    day_frac = float(parts[2])  # 21.342991 дня
    
    day = int(day_frac)  # 21
    fractional_day = day_frac - day  # 0.342991
    
    # Создаём дату
    dt = datetime(year, month, day)
    
    # Переводим дробную часть дня в часы, минуты, секунды
    seconds_in_day = fractional_day * 86400  # 86400 секунд в дне
    hours = int(seconds_in_day // 3600)
    minutes = int((seconds_in_day % 3600) // 60)
    seconds = seconds_in_day % 60
    
    # Устанавливаем время
    dt = dt.replace(hour=hours, minute=minutes, second=int(seconds),
                   microsecond=int((seconds - int(seconds)) * 1e6))
    
    return Time(dt, scale='utc')
```

**Что это делает:**

Астрономические данные дают дату в формате: год, месяц, день с дробью (0.342991 дня).

Функция конвертирует это в стандартный объект времени Python:

- `21.342991` дня = 21 день + 0.342991 × 86400 секунд = 21 день 8 часов 13 минут
- Результат: объект `Time` из библиотеки astropy, который понимает астрономические операции

## ЯЧЕЙКА 7: Парсинг координат

```python
def parse_coords(ra_str, dec_str):
    return SkyCoord(ra_str, dec_str, unit=(u.hourangle, u.deg), frame='icrs')
```

**Что это делает:**

Переводит координаты из текстового формата в объект `SkyCoord`:

- **RA (Right Ascension)** — даётся в часах, минутах, секундах (как часовой пояс, но для неба)
  - Пример: `09 50 04.192` = 9 часов 50 минут 4.192 секунды
  
- **Dec (Declination)** — даётся в градусах, минутах, секундах
  - Пример: `+43 47 13.29` = +43° 47' 13.29"

- **`unit=(u.hourangle, u.deg)`** — говорит, что RA в часовых углах, Dec в градусах
- **`frame='icrs'`** — используем стандартную небесную систему координат ICRS

**Результат:** объект, с которым можно работать астрономически.

## ЯЧЕЙКА 13: МЕТОД ГАУССА — основной алгоритм

Это самая сложная часть. Метод Гаусса — классический алгоритм определения орбиты из трёх наблюдений.

### Что здесь вычисляется:

```python
def gauss_method(rho_hat1, rho_hat2, rho_hat3, R1, R2, R3, t1, t2, t3, mu, max_iter=50, tol=1e-12):
```

**Входные данные:**
- **rho_hat1, rho_hat2, rho_hat3** — единичные векторы направлений на астероид из трёх наблюдений
- **R1, R2, R3** — позиции Земли относительно Солнца в три момента
- **t1, t2, t3** — времена наблюдений
- **mu** — гравитационный параметр Солнца

### Временные интервалы:

```python
tau1 = (t1 - t2).jd      # дни между наблюдениями 1 и 2
tau3 = (t3 - t2).jd      # дни между наблюдениями 3 и 2
tau  = (t3 - t1).jd      # дни между наблюдениями 1 и 3
```

**Результат:**
```
tau1 = -4.515 дней (наблюдение 1 было раньше наблюдения 2)
tau3 = 2.141 дней
tau = 6.656 дней
```

### D-коэффициенты:

```python
D0  = np.dot(rho_hat1, np.cross(rho_hat2, rho_hat3))
D11 = np.dot(np.cross(rho_hat2, rho_hat3), R1)
# и так далее...
```

**Что это такое?**

Это специальные коэффициенты, которые связывают наблюдаемые направления с неизвестными расстояниями до астероида. Используют векторное произведение (cross) и скалярное произведение (dot).

**Физический смысл:** эти коэффициенты учитывают геометрию задачи (где находятся Земля и в каком направлении виден астероид).

### Начальное приближение:

```python
r2_mag = vector_norm(R2)  # AU
```

**Идея:** в качестве первого приближения расстояния до астероида берём расстояние от Земли до Солнца (~1 AU).

**Почему?** Большинство астероидов находятся на расстояниях того же порядка.

### Итерационный цикл:

```python
for iteration in range(max_iter):
    if abs(r2_mag - r2_mag_old) < tol:
        break
    
    r2_mag_old = r2_mag
    
    # Коэффициенты Лагранжа f и g
    f1 = 1.0 - 0.5 * mu * tau1**2 / r2_mag**3
    f3 = 1.0 - 0.5 * mu * tau3**2 / r2_mag**3
    g1 = tau1 - (1.0/6.0) * mu * tau1**3 / r2_mag**3
    g3 = tau3 - (1.0/6.0) * mu * tau3**3 / r2_mag**3
```

**Что это?**

**Коэффициенты Лагранжа (f и g)** — это математический инструмент для описания кеплеровского движения:

- **f** — как положение в момент t связано с положением в момент t₀
- **g** — как скорость влияет на положение

Формулы с `mu * tau**2 / r2_mag**3` — это гравитационные эффекты в терминах масштаба расстояний и времени.

**Из этих коэффициентов вычисляются расстояния:**

```python
c1 = g3 / denominator
c3 = -g1 / denominator

rho1 = (-D11 * c1 + D21 - D31 * c3) / D0  # геоцентрическое расстояние до астероида в момент 1
rho2 = (-D12 * c1 + D22 - D32 * c3) / D0  # в момент 2
rho3 = (-D13 * c1 + D23 - D33 * c3) / D0  # в момент 3
```

Это размеры векторов `rho` — расстояния от Земли до астероида.

**Вычисление гелиоцентрических позиций:**

```python
r1_vec = R1 + rho1 * rho_hat1  # позиция астероида в момент 1
r2_vec = R2 + rho2 * rho_hat2  # позиция астероида в момент 2
r3_vec = R3 + rho3 * rho_hat3  # позиция астероида в момент 3
```

**Логика:**
```
r = R + ρ * rho_hat
  = (позиция Земли) + (расстояние до астероида) × (направление на астероид)
```

**Поправка на время распространения света:**

```python
light_time1 = rho1 / c_au_per_day
t1_corrected = t1 - light_time1 * u.day
```

**Суть:** свет не распространяется мгновенно! Если расстояние до астероида 1 AU, то свет идёт ~8.3 минуты. Значит, мы видим астероид не там, где он в момент наблюдения, а там, где он был 8.3 минуты назад.

**Обновление и проверка сходимости:**

```python
r2_mag = r2_mag_new
print(f"r2_mag = {r2_mag:.6f} AU, Δ = {abs(r2_mag - r2_mag_old):.2e}")
```

Процесс повторяется, пока расстояние не стабилизируется (Δ становится очень мала).

**Результат после 20 итераций:**

```

```

Астероид находится на расстоянии ~0.983 AU — в 98.3% от расстояния Земля-Солнце.

## ЯЧЕЙКА 14: Вычисление вектора скорости

```python
r2_mag = vector_norm(r2_vec)
f1 = 1.0 - 0.5 * mu * tau1**2 / r2_mag**3
# ... вычисляем f и g заново...

v2_vec = (-f3 * r1_vec + f1 * r3_vec) / denominator
```

**Что это делает:**

Используя окончательное расстояние r2_mag, пересчитываются коэффициенты Лагранжа и затем вычисляется **вектор скорости астероида**:

```
v = (-f3 * r1 + f1 * r3) / denominator
```

**Физический смысл:** скорость вычисляется через изменение положения на разных моментах времени, с учётом гравитационного притяжения.

## ЯЧЕЙКА 18: Моделирование направления

def model_direction(x, dt_i, R_obs_i):

2. Вычитаем позицию Земли → получаем вектор от Земли к астероиду
3. Нормализуем → получаем единичный вектор направления

## ЯЧЕЙКА 19: Невязки (остатки)

```python
def residuals(x):
    N = len(dt_all)
    res = np.zeros(3*N)  # 3 компоненты на каждое наблюдение
    for i in range(N):
        d_model = model_direction(x, dt_all[i], earth_sun_all[i])  # модель
        d_obs = rho_hat_all[i]  # наблюдение
        r_i = d_model - d_obs  # разница
        w = weights_sub[i]  # учитываем вес
        res[3*i:3*i+3] = w * r_i
    return res
```

**Что это делает:**

Для каждого наблюдения вычисляет **невязку** — разницу между моделью и наблюдением:

```
невязка_i = вес_i × (направление_модели - направление_наблюдения)
```

**Физический смысл:**

Если невязки близки к нулю, то наша модель хорошо согласуется с наблюдениями. Если нет — нужно улучшить параметры орбиты (x).

## ЯЧЕЙКА 20: Матрица Якоби

```python
def jacobian(x, eps=1e-6):
    r0 = residuals(x)
    m = r0.size  # количество компонент невязки
    n = x.size   # количество параметров (6)
    J = np.zeros((m, n))
    for j in range(n):
        dx = np.zeros_like(x)
        dx[j] = eps
        r_plus = residuals(x + dx)
        r_minus = residuals(x - dx)
        J[:, j] = (r_plus - r_minus) / (2*eps)
    return J
```

**Что это делает:**

Вычисляет матрицу Якоби — это показывает, **как изменяются невязки при небольших изменениях параметров**:

```
J[i,j] = ∂(невязка_i) / ∂(параметр_j)
```

**Численное дифференцирование:**

- Вычисляем невязки при x+eps и x-eps
- Разница деленная на 2eps ≈ производная

**Размер матрицы:**

- Строк: 3×1262 = 3786 (все компоненты всех направлений)
- Столбцов: 6 (параметры r и v)

**Зачем?**

Матрица Якоби нужна для метода Гаусса-Ньютона — она показывает, в каком направлении "толкать" параметры, чтобы уменьшить невязки.

## ЯЧЕЙКА 22: Метод Гаусса-Ньютона с регуляризацией

```python
def gauss_newton_tikhonov(x0, lambda_reg=0.2, max_iter=15, tol=1e-8):
    x = x0.copy()
    
    L = np.diag([1.0, 1.0, 10.0,   # r_x, r_y, r_z
                 1.0, 1.0, 10.0])  # v_x, v_y, v_z
    
    for k_iter in range(max_iter):
        r = residuals(x)
        J = jacobian(x)
        
        # Система Гаусса-Ньютона с регуляризацией Тихонова
        A = np.dot(J.T, J) + (lambda_reg**2) * np.dot(L.T, L)
        b = -np.dot(J.T, r) - (lambda_reg**2) * np.dot(np.dot(L.T, L), (x - x0))
        
        dx = solve_system(A, b)
        
        # Ограничиваем величину шага
        max_step = 0.01
        norm_dx = vector_norm(dx)
        if norm_dx > max_step:
            dx = dx * (max_step / norm_dx)
        
        x_new = x + dx
        
        if vector_norm(dx) < tol:
            return x_new
        
        x = x_new
    
    return x
```

**Что это делает:**

Это **итерационный метод оптимизации** для уточнения орбиты. Он уменьшает невязки, двигая параметры в "правильном направлении".

**Алгоритм:**

1. **Вычисляем невязки**: r = model - observations
2. **Вычисляем матрицу Якоби**: J = ∂r/∂x
3. **Решаем систему**: (J^T·J)·dx = -J^T·r
   - Это система, которая даёт поправку dx
4. **Ограничиваем шаг**: чтобы не "прыгнуть" слишком далеко
5. **Обновляем**: x_new = x + dx
6. **Повторяем**, пока dx не станет очень маленькой

**Регуляризация Тихонова:**

```python
A = J^T·J + λ²·L^T·L
b = -J^T·r - λ²·L^T·L·(x - x0)
```

**Зачем нужна?**

Без регуляризации система может быть нестабильной. Регуляризация:
- "Штрафует" большие отклонения от начального приближения
- Делает решение более устойчивым
- λ = 0.3 — параметр регуляризации

**Матрица L:**

```python
L = diag([1, 1, 10, 1, 1, 10])
```

Компоненты z-координаты (индексы 2 и 5) имеют больший вес (10 вместо 1). Это потому что они менее определены из наблюдений.

**Результат после 5 итераций:**

```
Уточненный r2: [-0.569, 0.737, 0.320] AU
Уточненный v2: [-0.0134, -0.00934, -0.00524] AU/день
```

Параметры немного изменились, что улучшило согласие с наблюдениями.
