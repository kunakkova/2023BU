# Проект: Расчет орбиты астероида 2023 BU

## Общее описание алгоритма

Проект использует **метод трёх наблюдений Гаусса** и последующее **уточнение методом Гаусса-Ньютона** для определения орбиты астероида по астрономическим наблюдениям.

### Алгоритм в общих чертах

1. **Загрузка данных** — читаем файл с наблюдениями астероида (координаты, времена, обсерватории)
2. **Выбор трех наблюдений** — берем три моменты времени с известными положениями астероида на небе
3. **Метод Гаусса** — вычисляем предварительную орбиту по этим трём наблюдениям
4. **Получение 6 орбитальных элементов** — преобразуем (r, v) в (a, e, i, Ω, ω, M₀)
5. **Подготовка большого набора наблюдений** — собираем все наблюдения в узком временном окне
6. **Численное интегрирование** — прогнозируем положения астероида на моменты наблюдений
7. **Метод Гаусса-Ньютона** — уточняем орбиту, минимизируя отклонения от наблюдений

### Ячейка 3: Загрузка и парсинг наблюдений

```python
def load_observations(filename):
    observations = []
    with open(filename, 'r', encoding='utf-8') as f:
        lines = f.readlines()
        data_lines = lines[1:]  # пропускаем заголовок
        for line in data_lines:
            line = line.strip()
            if not line:
                continue
            # разбиваем строку на компоненты
            parts = [x for x in line.split() if x]
            if len(parts) < 12:
                continue
            
            # извлекаем каждое поле
            date_ut = ' '.join(parts[0:3])        # дата и время
            ra = ' '.join(parts[3:6])             # прямое восхождение
            dec = ' '.join(parts[6:9])            # склонение
            magn = parts[9]                       # видимая яркость
            
            # обработка полей с переменной длиной
            location_start = 10
            if len(parts) > 10 and parts[10].isalpha() and len(parts[10]) == 1:
                magn += ' ' + parts[10]
                location_start += 1
            
            location = ' '.join(parts[location_start:-2]) if len(parts[location_start:-2]) > 0 else ''
            ref = ' '.join(parts[-2:])
            
            # проверка всех полей заполнены
            if not all([date_ut, ra, dec, magn, location, ref]):
                continue
            
            # создание словаря наблюдения
            obs = {
                'date_ut': date_ut,
                'ra': ra,
                'dec': dec,
                'magn': magn,
                'location': location,
                'ref': ref
            }
            observations.append(obs)
    return observations

filename = 'sample_data/2023_BU_data.txt'
obs = load_observations(filename)
print('Число загруженных наблюдений:', len(obs))
print('Пример наблюдения:', obs[0])
```

**Назначение:** Прочитать файл с астрономическими наблюдениями и преобразовать текстовые строки в структурированные данные.

**Что происходит подробно:**
- Открываем файл с кодировкой UTF-8
- Читаем все строки, пропускаем первую (заголовок)
- Для каждой строки:
  - Удаляем пробелы по краям (`strip()`)
  - Разбиваем на компоненты по пробелам
  - Извлекаем дату (год, месяц, день с дробной частью)
  - Извлекаем RA (часы минуты секунды в небесных координатах)
  - Извлекаем Dec (градусы минуты секунды в небесных координатах)
  - Извлекаем видимую яркость (магнитуду)
  - Извлекаем код обсерватории и название
  - Извлекаем номер ссылки каталога
- Сохраняем в список словарей
- Выводим количество загруженных наблюдений

**Простыми словами:** Берем файл с множеством наблюдений астероида (когда его видели, где, с какой яркостью) и превращаем текст в удобный компьютерный формат.

### Ячейка 6: Парсинг даты

```python
def parse_date(date_str):
    parts = date_str.split()
    year = int(parts[0])
    month = int(parts[1])
    day_frac = float(parts[2])
    
    day = int(day_frac)
    fractional_day = day_frac - day
    
    dt = datetime(year, month, day)
    
    # преобразуем дробную часть дня в часы, минуты, секунды
    seconds_in_day = fractional_day * 86400
    hours = int(seconds_in_day // 3600)
    minutes = int((seconds_in_day % 3600) // 60)
    seconds = seconds_in_day % 60
    
    dt = dt.replace(hour=hours, minute=minutes, second=int(seconds),
                   microsecond=int((seconds - int(seconds)) * 1e6))
    
    t_utc = Time(dt, scale='utc')
    
    # вычисляем количество секунд от эпохи J2000
    dt_seconds = (t_utc.jd - J2000_epoch.jd) * 86400.0
    
    return t_utc, dt_seconds
```

**Назначение:** Преобразовать строку даты из формата файла в объект Time и вычислить количество секунд от J2000.

**Что происходит подробно:**
- Разбиваем строку на год, месяц, день с дробной частью
- День может быть дробным, например 15.5 = 15-й день в 12:00
- Выделяем целую часть дня и дробную
- Дробная часть дня преобразуется в часы, минуты, секунды:
  - Дробная часть × 86400 сек = количество секунд в этот день
- Создаем объект DateTime в Python
- Создаем объект Time из astropy (это работает с астрономическими системами отсчета)
- Вычисляем юлианский день (JD) и находим разницу с эпохой J2000
- Возвращаем оба представления времени

**Простыми словами:** Берем дату из файла (например, "2023 1 10.5") и превращаем ее в стандартный формат, плюс считаем, сколько секунд прошло с начала нашей системы отсчета (J2000).

### Ячейка 8: Получение позиции обсерватории

```python
def get_observatory_position(obs_code, t_utc):
    if obs_code not in observatory_coords:
        earth_pos, _ = get_body_barycentric_posvel('earth', t_utc)
        return earth_pos.xyz.to(u.au).value
    
    obs_info = observatory_coords[obs_code]
    lon_deg = obs_info['lon']
    lat_deg = obs_info['lat']
    alt_m = obs_info['alt']
    
    # параметры эллипсоида Земли (WGS84)
    a_earth = 6378137.0
    f = 1.0 / 298.257223563
    
    # вычисляем эксцентриситет
    e2 = 2*f - f*f
    sin_lat = np.sin(np.deg2rad(lat_deg))
    N = a_earth / np.sqrt(1 - e2 * sin_lat**2)
    
    # преобразуем географические координаты в декартовы (ITRS)
    cos_lat = np.cos(np.deg2rad(lat_deg))
    cos_lon = np.cos(np.deg2rad(lon_deg))
    sin_lon = np.sin(np.deg2rad(lon_deg))
    
    x_itrs = (N + alt_m) * cos_lat * cos_lon
    y_itrs = (N + alt_m) * cos_lat * sin_lon
    z_itrs = (N * (1 - e2) + alt_m) * sin_lat
    
    # преобразуем из ITRS (земная система) в GCRS (небесная система)
    itrs_coord = ITRS(x=x_itrs*u.m, y=y_itrs*u.m, z=z_itrs*u.m, obstime=t_utc)
    gcrs_coord = itrs_coord.transform_to(GCRS(obstime=t_utc))
    
    pos_au = gcrs_coord.cartesian.xyz.to(u.au).value
    
    return pos_au
```

**Назначение:** Вычислить точное положение обсерватории в момент наблюдения в гелиоцентрической системе координат.

**Что происходит подробно:**
- Если код обсерватории неизвестен, используем центр Земли
- Если известен:
  - Извлекаем долготу, широту и высоту из справочника
  - Используем модель Земли WGS84 (эллипсоид):
    - a_earth = 6378137 м — экваториальный радиус
    - f = 1/298.257 — сплющенность
  - Вычисляем радиус кривизны N (зависит от широты)
  - Преобразуем географические координаты (lon, lat, alt) в декартовы (x, y, z) в системе ITRS:
    - ITRS — земная система, вращается с Землей
    - Формулы учитывают, что Земля — не идеальный шар
  - Преобразуем из ITRS в GCRS (небесная система координат):
    - GCRS не вращается с Землей, это инерциальная система
    - Астрономы используют эту систему для позиций звезд
  - Преобразуем результат в астрономические единицы (AU)

**Простыми словами:** Узнаем точное 3D-положение телескопа на Земле, учитывая, что Земля круглая (точнее, сплющенная), и преобразуем это в систему координат, которая не вращается с Землей.

### Ячейка 13: Метод Гаусса для трёх наблюдений

```python

                 t1_sec, t2_sec, t3_sec, mu, max_iter=50, tol=1e-12):
    # Временные интервалы
    tau1 = t1_sec - t2_sec
    tau3 = t3_sec - t2_sec
    tau  = t3_sec - t1_sec

    D0  = np.dot(rho_hat1, np.cross(rho_hat2, rho_hat3))
    D11 = np.dot(np.cross(rho_hat2, rho_hat3), R1)
    # ... (9 коэффициентов всего)
    
    r2_mag = vector_norm(R2)
    
    for iteration in range(max_iter):
        # Вычисляем функции Тейлора (f и g)
        f1 = 1.0 - 0.5 * mu * tau1_days**2 / r2_mag**3
        f3 = 1.0 - 0.5 * mu * tau3_days**2 / r2_mag**3

        denominator = f1 * g3 - f3 * g1
        c1 = g3 / denominator
        c3 = -g1 / denominator
        
        # Вычисляем расстояния от Земли до астероида
        rho1 = (-D11 * c1 + D21 - D31 * c3) / D0
        rho2 = (-D12 * c1 + D22 - D32 * c3) / D0
        rho3 = (-D13 * c1 + D23 - D33 * c3) / D0
        
        # Вычисляем позиции астероида
        r1_vec = R1 + rho1 * rho_hat1
        r2_vec = R2 + rho2 * rho_hat2

        t1_corrected = t1_sec - light_time1
        t2_corrected = t2_sec - light_time2
        t3_corrected = t3_sec - light_time3
        
        # Пересчитываем временные интервалы
        tau1 = t1_corrected - t2_corrected
        tau3 = t3_corrected - t2_corrected
        tau  = t3_corrected - t1_corrected
        
        r2_mag = r2_mag_new
```

**Назначение:** Применить метод Гаусса для трёх наблюдений и получить предварительную орбиту.

**Что происходит подробно:**

Метод Гаусса — это классический способ определения орбиты по трём наблюдениям. Основная идея:

1. **Временные интервалы:**
   - Берем времена т1, т2, т3 трёх наблюдений
   - Вычисляем τ1 = т1 - т2 и τ3 = т3 - т2 (интервалы относительно среднего наблюдения)

2. **D-коэффициенты (триплетные произведения):**
   - D0 = ρ̂₁ · (ρ̂₂ × ρ̂₃) — мера того, лежат ли три направления в одной плоскости
   - Остальные D — комбинации векторных произведений с позициями обсерваторий
   - Они решают систему уравнений для расстояний

3. **Функции Тейлора f и g:**
   - Используются для экстраполяции орбиты между наблюдениями
   - f ≈ 1 - ½ μ τ²/r³ — показывает, как меняется направление за время τ
   - g ≈ τ - ⅙ μ τ³/r³ — показывает, как меняется расстояние за время τ

4. **Итеративный процесс:**
   - Начинаем с начального приближения r₂ (примерно равно R₂ — расстояние до Земли)
   - В каждой итерации:
     - Вычисляем f и g
     - Вычисляем коэффициенты c₁ и c₃
     - Вычисляем расстояния ρ₁, ρ₂, ρ₃ (от Земли до астероида в моменты наблюдений)
     - Вычисляем позиции астероида: r = R + ρ·ρ̂
     - Учитываем задержку света: наблюдение пришло на Землю позже, чем произошло
     - Пересчитываем временные интервалы
     - Обновляем r₂
   - Повторяем, пока r₂ не сойдется (не изменится на величину < tol)

5. **Результат:**
   - Получаем позиции астероида в моменты трёх наблюдений (r₁, r₂, r₃)
   - И расстояния от Земли (ρ₁, ρ₂, ρ₃)

**Простыми словами:** Это детективная работа. Мы видим астероид с трёх разных точек (обсерватории на Земле, которая движется). Метод Гаусса — как решить, где на самом деле находится астероид, чтобы все три наблюдения совпадали с его реальной орбитой.

**Назначение:** Преобразовать (r, v) в 3 основных орбитальных элемента: a, e, i.

**Что происходит подробно:**

Из вектора положения **r** и вектора скорости **v** можно вычислить орбиту:

1. **Угловой момент** **h** = **r** × **v**:
   - Показывает направление оси вращения орбиты
   - Если h параллелен оси Z, то орбита в плоскости XY (экватор)
   - h_z = |**h**| · cos(i)

2. **Наклонение** i = arccos(h_z / |**h**|):
   - Угол между плоскостью орбиты и эклиптикой
   - i = 0° — орбита в плоскости Земли
   - i = 90° — орбита перпендикулярна

3. **Вектор восходящего узла** **n** = [0, 0, 1] × **h**:
   - Указывает на восходящий узел (где орбита пересекает эклиптику)
   - Нужен для определения других углов

4. **Вектор эксцентриситета** **e** = (**v** × **h**)/μ - **r**/r:
   - Формула из уравнений Кеплера
   - Указывает в сторону перицентра (ближайшей точки)
   - |**e**| = e — эксцентриситет (0 = круг, 1 = парабола)

5. **Большая полуось** a = -μ / (2E), где E — энергия орбиты:
   - E = v²/2 - μ/r (кинетическая + потенциальная энергия)
   - Связь: a определяет период обращения (третий закон Кеплера)

**Простыми словами:** Зная, где находится астероид и с какой скоростью движется, можно определить форму его орбиты (вытянутая или круглая), наклон и размер.

### Ячейка 17: DOPRI5 интегратор

```python
class DOPRI5Integrator:
    c = np.array([0, 1/5, 3/10, 4/5, 8/9, 1, 1])
    a = np.array([
        [0, 0, 0, 0, 0, 0],
        [1/5, 0, 0, 0, 0, 0],
        [3/40, 9/40, 0, 0, 0, 0],
        [44/45, -56/15, 32/9, 0, 0, 0],
        [19372/6561, -25360/2187, 64448/6561, -212/729, 0, 0],
        [9017/3168, -355/33, 46732/5247, 49/176, -5103/18656, 0],
        [35/384, 0, 500/1113, 125/192, -2187/6784, 11/84]
    ])
    
    b = np.array([35/384, 0, 500/1113, 125/192, -2187/6784, 11/84, 0])
    
    def __init__(self, mu):
        self.mu = mu
    
    def ode(self, t, y):
        r = y[:3]
        v = y[3:]
        r_norm = vector_norm(r)
        if r_norm < 1e-10:
            return np.zeros_like(y)
        drdt = v
        dvdt = -self.mu * r / (r_norm**3)
        return np.concatenate([drdt, dvdt])
    
    def step(self, y, t, dt):
        h = dt
        k = np.zeros((7, len(y)))
        
        for i in range(7):
            t_i = t + self.c[i] * h
            y_i = y.copy()
            
            for j in range(i):
                y_i += h * self.a[i, j] * k[j]
            
            k[i] = self.ode(t_i, y_i)
        
        y_new = y + h * np.dot(self.b, k)
        
        return y_new
    
    def integrate(self, y0, t_span, num_points=2):
        t_start, t_end = t_span
        t_eval = np.linspace(t_start, t_end, num_points)
        dt = (t_end - t_start) / (num_points - 1)
        
        solution = np.zeros((num_points, len(y0)))
        solution[0] = y0
        
        for i in range(num_points - 1):
            solution[i+1] = self.step(solution[i], t_eval[i], dt)
        
        return t_eval, solution
```

**Назначение:** Реализовать численный интегратор DOPRI5 (Dormand-Prince 5-го порядка) для интегрирования уравнений движения.

**Что происходит подробно:**

DOPRI5 — это явный метод Рунге-Кутта 5-го порядка точности. Используется для решения дифференциальных уравнений вида dy/dt = f(t, y).

1. **Матрицы коэффициентов:**
   - c = [0, 1/5, 3/10, 4/5, 8/9, 1, 1] — узлы (временные точки)
   - a — коэффициенты для вычисления промежуточных значений
   - b — коэффициенты для финального результата

2. **Дифференциальное уравнение (ODE):**
   - y = [r, v] = [x, y, z, vx, vy, vz]
   - dr/dt = v (скорость — производная положения)
   - dv/dt = -μr/r³ (ускорение — ньютонова гравитация)

3. **Метод step:**
   - За один шаг времени dt вычисляем новое значение y
   - Используем 7 вспомогательных вычислений (k₀...k₆)
   - Каждое k — это ODE, вычисленная в разные промежуточные моменты
   - Финальный результат = сумма взвешенных k с коэффициентами b

4. **Метод integrate:**
   - Интегрируем от t_start до t_end
   - Разбиваем интервал на num_points временных точек
   - На каждом шаге вызываем step()

**Простыми словами:** Это программный способ решить уравнение "как летит астероид под действием притяжения Солнца". Знаем начальное положение и скорость, вычисляем положение через какое-то время.

### Ячейка 18: Линейная интерполяция

```python
def linear_interp(t1, t2, t3, f1, f2):
    alpha = (t3 - t1) / (t2 - t1)
    return f1 + alpha * (f2 - f1)
```

**Назначение:** Интерполировать значение функции в промежуточный момент времени.

**Что происходит подробно:**
- Знаем значение f в моменты t1 и t2
- Хотим найти f в момент t3 (между t1 и t2)
- Вычисляем параметр α = (t3 - t1) / (t2 - t1), где 0 < α < 1
- Используем линейную интерполяцию: f(t3) ≈ f1 + α(f2 - f1)

**Простыми словами:** Рисуем линию между двумя точками и находим значение в промежуточной точке.

### Ячейка 19: Функция невязок

```python
def residuals_dopri5(x):
    N = len(dt_all_days)
    res = np.zeros(3 * N)
    r0 = x[:3]
    v0 = x[3:]
    integrator = DOPRI5Integrator(mu)
    
    for i in range(N):
        try:
            t_obs = dt_all_days[i]
            r_earth = earth_sun_all[i]
            
            # Интегрируем орбиту от т=0 до т=t_obs
            num_points = max(2, int(abs(t_obs) * 100) + 1)
            t_model, y_model = integrator.integrate(
                np.concatenate([r0, v0]),
                [0.0, t_obs],
                num_points=num_points
            )
            
            # Находим позицию астероида в момент наблюдения
            if np.any(np.isclose(t_model, t_obs)):
                idx = np.where(np.isclose(t_model, t_obs))[0][0]
                r_ast = y_model[idx, :3]
            else:
                idx = np.searchsorted(t_model, t_obs) - 1
                idx = np.clip(idx, 0, len(t_model) - 2)
                
                t1, t2 = t_model[idx], t_model[idx + 1]
                r1 = y_model[idx, :3]
                r2 = y_model[idx + 1, :3]
                
                r_ast = linear_interp(t1, t2, t_obs, r1, r2)
            
            # Вычисляем направление к астероиду
            rho_vec = r_ast - r_earth
            rho_hat_model = rho_vec / vector_norm(rho_vec)
            
            rho_hat_obs = rho_hat_all[i]
            
            # Невязка = разница между моделью и наблюдением
            res[3*i:3*i+3] = rho_hat_model - rho_hat_obs
        
        except Exception as e:
            print(f"Ошибка в наблюдении {i}: {e}")
            res[3*i:3*i+3] = np.array([1e6, 1e6, 1e6])
    
    return res
```

**Назначение:** Вычислить вектор невязок (отклонения предсказанных позиций от наблюдаемых).

**Что происходит подробно:**

Невязка показывает, на сколько модель отличается от данных:

1. **Для каждого наблюдения i:**
   - Берем время наблюдения t_obs
   - Берем позицию обсерватории R_earth
   
2. **Интегрируем орбиту:**
   - Используем DOPRI5 для интегрирования уравнений движения
   - Начальное условие: (r₀, v₀) — текущая оценка орбиты
   - От времени 0 до времени t_obs
   - Числом точек, пропорциональным |t_obs|
   
3. **Находим позицию астероида:**
   - Если интегратор дошел точно до t_obs, берем результат
   - Иначе интерполируем между двумя ближайшими точками
   
4. **Вычисляем направление (единичный вектор):**
   - ρ_hat_model = (r_ast - R_earth) / |r_ast - R_earth|
   - Это направление, в котором модель предсказывает видеть астероид
   
5. **Сравниваем с наблюдением:**
   - ρ_hat_obs — единичный вектор, в направлении которого астероид реально наблюдался
   - Невязка = ρ_hat_model - ρ_hat_obs
   - Это вектор размером 3 × N_наблюдений

**Простыми словами:** Берем текущую оценку орбиты, прогнозируем, где должен быть астероид в каждый момент наблюдения, и сравниваем с тем, где его реально видели. Разница — это невязка.

### Ячейка 20: Матрица Якоби

```python
def jacobian_dopri5(x, eps=1e-6):
    r0 = residuals_dopri5(x)
    m = r0.size
    n = x.size
    J = np.zeros((m, n))
    
    for j in range(n):
        dx = np.zeros_like(x)
        dx[j] = eps
        try:
            r_plus = residuals_dopri5(x + dx)
            r_minus = residuals_dopri5(x - dx)
            J[:, j] = (r_plus - r_minus) / (2*eps)
        except Exception as e:
            print(f"Ошибка при вычислении производной по параметру {j}: {e}")
            J[:, j] = 0
    
    return J
```

**Назначение:** Вычислить матрицу Якоби (матрицу частных производных невязок по параметрам).

**Что происходит подробно:**

Матрица Якоби J размером (3N) × 6 показывает, как меняются невязки при небольших изменениях параметров орбиты:

- Строки — это компоненты невязок (3 компоненты × N наблюдений)
- Столбцы — это параметры орбиты (r, v) = 6 параметров
- J[i, j] = ∂res[i] / ∂x[j]

**Численное дифференцирование:**
- Для каждого параметра j:
  - Вычисляем невязки при x + ε·e_j (сдвиг вперед)
  - Вычисляем невязки при x - ε·e_j (сдвиг назад)
  - Производная ≈ (r_plus - r_minus) / (2ε)
  - Это центральная разностная формула (точнее, чем односторонняя)

**Простыми словами:** Показывает, как изменятся ошибки предсказания, если мы слегка изменим оценку позиции или скорости астероида.

### Ячейка 21: LUP-разложение

```python
def LUP_decomposition(A):
    n = len(A)
    A = np.array(A, dtype=float)
    P = np.eye(n)
    L = np.zeros((n, n))
    U = np.zeros((n, n))
    
    for k in range(n):
        # Выбираем ведущий элемент (pivot) — наибольший по модулю
        pivot_row = k + np.argmax(np.abs(A[k:, k]))
        
        # Перестановка строк
        if pivot_row != k:
            A[[k, pivot_row]] = A[[pivot_row, k]]
            P[[k, pivot_row]] = P[[pivot_row, k]]
            if k > 0:
                L[[k, pivot_row], :k] = L[[pivot_row, k], :k]
        
        # Проверка сингулярности
        if abs(A[k, k]) < 1e-12:
            raise ValueError("Матрица вырождена или почти вырождена")
        
        # Заполнение L и U
        L[k, k] = 1.0
        U[k, k:] = A[k, k:]
        L[k+1:, k] = A[k+1:, k] / A[k, k]
        for i in range(k+1, n):
            for j in range(k+1, n):
                A[i, j] -= L[i, k] * U[k, j]
    
    return L, U, P

def LUP_solve(L, U, P, b):
    n = len(L)
    Pb = np.dot(P, b)
    
    # Прямая подстановка: L·y = P·b
    y = np.zeros(n)
    for i in range(n):
        y[i] = Pb[i] - np.dot(L[i, :i], y[:i])
    
    # Обратная подстановка: U·x = y
    x = np.zeros(n)
    for i in range(n-1, -1, -1):
        x[i] = (y[i] - np.dot(U[i, i+1:], x[i+1:])) / U[i, i]
    
    return x

def solve_system(A, b):
    L, U, P = LUP_decomposition(A)
    return LUP_solve(L, U, P, b)
```

**Назначение:** Разложить матрицу A = LUP и решить систему линейных уравнений A·x = b.

**Что происходит подробно:**

**LUP-разложение (LU с частичным выбором ведущего элемента):**

Матрица A разлагается на три матрицы:
- L — нижняя треугольная матрица (Lower triangular)
- U — верхняя треугольная матрица (Upper triangular)
- P — матрица перестановок (Permutation)

Такая что: **P·A = L·U** (или A = P⁻¹·L·U)

**Алгоритм:**
1. Для каждого столбца k:
   - Выбираем ведущий элемент (pivot) — наибольший по модулю ниже диагонали
   - Переставляем строки, чтобы ведущий элемент оказался на диагонали
   - Это повышает численную стабильность
   
2. Заполняем L и U элементами матрицы A

**Решение системы:**
Исходная система: A·x = b
После разложения: P·A = L·U, или **L·U·x = P·b**

Решаем в два этапа:
1. Прямая подстановка: **L·y = P·b** (легко, так как L треугольная)
2. Обратная подстановка: **U·x = y** (легко, так как U треугольная)

**Простыми словами:** Это способ быстро решить систему линейных уравнений, разбив большую сложную матрицу на две треугольные (которые легче обрабатывать).

### Ячейка 22: Метод Гаусса-Ньютона

```python
def gauss_newton(x0, lambda_reg=0.3, max_iter=5, tol=1e-8):
    x = x0.copy()
    
    # Матрица регуляризации
    L = np.diag([1.0, 1.0, 10.0,   # r_x, r_y, r_z
                 1.0, 1.0, 10.0])  # v_x, v_y, v_z
    
    for k_iter in range(max_iter):
        print(f"\nИтерация Гаусса-Ньютона {k_iter + 1}/{max_iter}")
        
        if not np.all(np.isfinite(x)):
            print("x содержит NaN/inf, останавливаемся")
            break
        
        # Вычисляем невязки
        r = residuals_dopri5(x)
        
        # Вычисляем матрицу Якоби
        J = jacobian_dopri5(x)
        
        # Нормальные уравнения с регуляризацией
        A = np.dot(J.T, J) + (lambda_reg**2) * np.dot(L.T, L)
        b = -np.dot(J.T, r) - (lambda_reg**2) * np.dot(np.dot(L.T, L), (x - x0))
        
        # Решаем систему линейных уравнений
        try:
            dx = solve_system(A, b)
        except ValueError as e:
            print(f"Ошибка при решении системы: {e}")
            break
        
        # Ограничиваем размер шага
        max_step = 0.01
        norm_dx = vector_norm(dx)
        if norm_dx > max_step:
            dx = dx * (max_step / norm_dx)
        
        x_new = x + dx
        if not np.all(np.isfinite(x_new)):
            print("dx привел к NaN/inf, уменьши шаг или lambda_reg")
            break
        
        print(f"Норма шага dx: {norm_dx:.6e}")
        
        # Проверка сходимости
        if norm_dx < tol:
            print(f"Сходимость достигнута на итерации {k_iter + 1}")
            return x_new
        
        x = x_new
    
    return x
```

**Назначение:** Применить метод Гаусса-Ньютона для уточнения орбиты путем минимизации невязок.

**Что происходит подробно:**

Метод Гаусса-Ньютона — это итеративный алгоритм оптимизации для задач наименьших квадратов:

**Цель:** найти x, минимизирующий ||r(x)||² (сумму квадратов невязок)

**Алгоритм на каждой итерации:**

1. **Вычисляем невязки:**
   - r = residuals_dopri5(x) — вектор размером 3N

2. **Вычисляем матрицу Якоби:**
   - J = ∂r/∂x — матрица размером (3N) × 6
   - Показывает, как меняются невязки при изменении x

3. **Нормальные уравнения (без регуляризации):**
   - (J^T · J) · dx = -J^T · r
   - Это система размером 6 × 6

4. **Регуляризация (Тихоновская):**
   - Добавляем штраф за изменение параметров: (λ·L)^T · (λ·L)
   - L = diag(1, 1, 10, 1, 1, 10) — разные веса для разных компонент
   - z-компоненты имеют вес 10 (так как они менее надежны)
   - Уравнение: (J^T·J + λ²·L^T·L) · dx = -J^T·r - λ²·L^T·L·(x - x₀)

5. **Решаем систему:**
   - Используем LUP-разложение для решения A·dx = b
   - Получаем поправку dx

6. **Ограничиваем шаг:**
   - Берем не полный шаг dx, а ограниченный: dx_new = dx · (max_step / ||dx||)
   - max_step = 0.01 — чтобы не прыгнуть слишком далеко

7. **Обновляем параметры:**
   - x_new = x + dx

8. **Проверяем сходимость:**
   - Если ||dx|| < tol, алгоритм сходился
   - Иначе повторяем со следующей итерации

**Простыми словами:** Это как найти минимум функции, двигаясь маленькими шагами в направлении, указанном градиентом. Каждый шаг уменьшает ошибку предсказания.

## Почему орбита характеризуется именно 6 параметрами?

### Теоретическое обоснование

Орбита в трёхмерном пространстве определяется начальными условиями: положением **r** и скоростью **v**. Это два 3D-вектора, всего **6 скалярных компонент** (r_x, r_y, r_z, v_x, v_y, v_z).

Однако два вектора в пространстве имеют математическую структуру. Уравнение движения:

\[ \frac{d^2 \mathbf{r}}{dt^2} = -\frac{\mu}{r^3} \mathbf{r} \]

имеет несколько **интегралов движения** (величин, которые не меняются во времени):

1. **Энергия E = v²/2 - μ/r** — сумма кинетической и потенциальной энергии
   - Определяет большую полуось: a = -μ/(2E)

2. **Угловой момент h = r × v** — момент импульса (вектор)
   - Его модуль |h| определяет форму орбиты совместно с E
   - Эксцентриситет: e = √(1 + 2E|h|²/μ²)
   - Направление h определяет наклонение i и долготу восходящего узла Ω

3. **Вектор Лапласа e (эксцентриситета)** — определяет ориентацию больших/малых осей

Эти три интеграла движения — скаляр, вектор и вектор — в сумме дают **6 независимых величин**, которые и выбирают из бесконечного множества возможных орбит одну конкретную.

### Орбитальные элементы как параметризация

Вместо прямого использования (r, v), астрономы используют **оскулирующие элементы** — более удобную параметризацию:

| Элемент | Обозначение | Смысл |
|---------|-------------|-------|
| **Большая полуось** | a | Характеристический размер орбиты; определяет период (3-й закон Кеплера) |
| **Эксцентриситет** | e | Вытянутость орбиты: e=0 (круг), 0<e<1 (эллипс), e=1 (парабола) |
| **Наклонение** | i | Угол между плоскостью орбиты и эклиптикой (плоскость орбиты Земли) |
| **Долгота восходящего узла** | Ω | Угол в эклиптике, определяющий положение восходящего узла |
| **Аргумент перицентра** | ω | Угол в плоскости орбиты, определяющий ориентацию эллипса |
| **Средняя аномалия** | M₀ | Угловое положение на орбите в данный момент времени |

### Геометрическое понимание

Орбита — это эллипс в 3D-пространстве. Чтобы полностью определить эллипс, нужно:

- **2 параметра** для формы и размера: a, e
- **2 параметра** для ориентации оси эллипса в пространстве: i, Ω, (+ неявно в ω)
- **1 параметр** для положения оси на плоскости: ω
- **1 параметр** для положения точки на эллипсе: M₀ (или ν)

**Всего: 6 параметров**

### Физический смысл

1. **a и e** — описывают формму траектории (кем внутри Солнечной системы летит астероид)
2. **i, Ω, ω** — описывают ориентацию орбиты в пространстве (как повернута эта орбита)
3. **M₀** — описывает, где именно на орбите находится астероид в данный момент

Вместе эти 6 чисел полностью определяют, как будет двигаться астероид в будущем (в гравитационном поле Солнца).
